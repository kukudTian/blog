Windows C盘满了？5步释放30GB空间（2026实测有效）

你的 C 盘是不是也快爆了？150GB 的盘只剩十几 GB，打开软件都卡？

今天帮朋友实测了一套清理方案，从 12.7GB 释放到 37.1GB，总共清出约 24GB 空间。以下是完整步骤。

第一步：清理已卸载软件的残留缓存

很多人卸载软件后，AppData 里的缓存文件还在。比如达芬奇（DaVinci Resolve）卸载后，AppData\Roaming\Blackmagic Design 目录下还有 2.5GB 的项目缓存。

检查方法：

看看哪些文件夹属于已经卸载的软件，直接删除即可。

常见大缓存：

  • Blackmagic Design（达芬奇）：2-5GB
  • Adobe 残留：1-3GB
  • 各种播放器/直播软件缓存

第二步：清空回收站

这个很多人忽略。回收站里的文件仍然占用 C 盘空间，实测清了 3.93GB。

右键回收站 → 清空回收站，搞定。

第三步：虚拟内存搬家（释放 16GB！）

这是最大的一块。Windows 默认把虚拟内存（pagefile.sys）放在 C 盘，通常占用 8-16GB。

操作步骤：

  1. 按 Win + R，输入 sysdm.cpl，回车
  2. 点「高级」选项卡 → 性能区域点「设置」
  3. 再点「高级」选项卡 → 虚拟内存区域点「更改」
  4. 取消勾选「自动管理所有驱动器的分页文件大小」
  5. 选中 C 盘 → 选「无分页文件」→ 点「设置」
  6. 选中 D 盘（或其他空间大的盘） → 选「自定义大小」
    • 初始大小：16384（16GB）
    • 最大值：20480（20GB）
    • 点「设置」
  7. 点「确定」→ 重启电脑

重启后 C 盘会多出 16GB 空间！

⚠️ 注意：D 盘需要有足够空间（建议至少 20GB 剩余）。

第四步：用磁盘清理工具

Windows 自带的磁盘清理可以清掉系统临时文件、Windows 更新缓存等：

  1. 右键 C 盘 → 属性 → 磁盘清理
  2. 点「清理系统文件」
  3. 勾选：Windows 更新清理、临时文件、缩略图等
  4. 点确定

第五步：检查大软件的缓存设置

有些软件默认把缓存放在 C 盘，可以改到其他盘：

  • Chrome：设置 → 隐私与安全 → 清除浏览数据
  • 微信/QQ：设置里改文件存储路径到 D 盘
  • pip（Python）：pip cache purge 清理包缓存
  • 剪映/Pr：在软件设置里改缓存目录

清理效果汇总

项目 释放空间
达芬奇残留缓存 2.5 GB
回收站 3.93 GB
虚拟内存搬家 ~16 GB
其他临时文件 ~2 GB
合计 ~24 GB

C 盘从 12.7GB → 37.1GB，系统流畅多了！

总结

虚拟内存搬家是性价比最高的操作，一次释放 16GB。配合清理残留缓存和回收站，轻松省出 20GB+ 的空间。

如果你的 C 盘也快满了，试试这几步，有问题欢迎留言交流！
